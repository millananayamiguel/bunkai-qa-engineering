## Synchronization limitations

The pull completed with 59 warnings. Xray GraphQL membership lookups could not enrich some records and the tool used Jira links; membership-only Tests may therefore appear as orphans. The tool reported 496 Tests without Story/Bug/Improvement coverage, one orphan Defect (BK-621), and skipped the parentless Story BK-492. Several ATP/ATR and Defect links use unexpected types. These are source-data/enrichment limitations, not corrected records.

Test Set, Precondition, Tech Debt, Tech Story and Improvement types were not included by that command's configured scope. This dated export does not claim complete coverage of every Jira work type.
